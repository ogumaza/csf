In CSF 1.5.0, a rip of The Wind Waker HD holds the sound effects that read a value from the game. Each such effect gets a variant for each value. Other rips are unchanged from 1.4.2.

CSF rips Nintendo Wii U sequenced music into a PSF-family format. It plays the music with the game's sound code or a model of that code, along with a model of the console's mixing. The release includes a ripper (`csfrip`), a renderer (`csfplay`), a foobar2000 component and an XMPlay plugin. `docs/csf.md` describes the format.

## New in 1.5.0

- **The Wind Waker HD's effects that read a value.** Some of The Wind Waker HD's effects read a value that the game gives them when it starts them. One such value is the material of the ground under a footstep. The player passed 0 for that value. Those effects played nothing in a rip. `csfrip` skipped them. A rip now holds a variant of each such effect for each value that plays other samples. Values that play the same samples share one variant. A variant's title is the effect's name, a space and the value, such as `6=4`. A new tag, `csf_var`, holds the value. `docs/csf.md` describes it. A player plays another variant when the tag holds another value. The foobar2000 component keeps the tag when it rewrites a file's tags. The XMPlay plugin leaves it out of the Message window. Earlier players ignore the tag. A variant then plays nothing in them.

## Features

- **Ripping.** `csfrip` rips a Wii U game or a sound archive (`.bfsar`) into a `.csflib` and a `.minicsf` for each sequence. A game can be a Wii U archive (`.wua`) or an extracted title. `csfrip` requires the game's files to be stored decrypted, and both forms store them that way. Cemu's Title Manager converts disc images (WUD and WUX) and installable titles to `.wua` files. `csfrip` finds the group files that a game keeps outside its sound archive. It also looks for them in SARC archives. The ripper plays each sound to work out its length and fade tags, and skips the sounds that make no sound. A rip of The Wind Waker HD holds the game's sound effects too. An effect that reads a value from the game gets a variant for each value. `--bgm` rips only the music. `csfrip` also supports drag and drop.
- **Two rip modes.** Game mode runs the game's sound code on an emulated Espresso CPU. The rips play as they do in the game. Game mode requires a driver profile for the game. Three games have one: Animal Crossing: amiibo Festival (USA), on NintendoWare's sound library, The Legend of Zelda: Twilight Princess HD (USA), on JAudio2, and The Legend of Zelda: The Wind Waker HD (USA), on JAudio1. Archive mode plays a sound archive from any game with CSF's model of the SDK's sound library. The model follows the version of the library in amiibo Festival.
- **The console's mixing.** The Wii U mixes its voices on a DSP. The DSP's program comes with the system rather than the game. The system's sound library then mixes the result for each output. In both modes, CSF does both stages in code: the voices' resampling, filters, envelopes and volumes, and the final mix stage with its upsampling to 48 kHz. The code does the same arithmetic as the DSP's program. A JAudio game mixes its voices on the CPU instead, and the player runs the game's mixer before the final mix stage.
- **Effects.** Archive mode plays the reverb, chorus and delay that a game sets up, for a game with an effect profile. Animal Crossing: amiibo Festival (USA) and Mario Party 10 (USA) have one.
- **Rendering.** `csfplay` renders rips to WAV or FLAC at the Wii U's 48,000 Hz.
- **foobar2000.** The component plays `.minicsf` files using their length and fade tags. Tag editing, ReplayGain and endless playback are supported. A separate thread renders ahead of playback and keeps up to ten minutes of audio. That makes seeking within a track quick.
- **XMPlay.** The plugin plays `.minicsf` files using their length and fade tags. Endless playback is supported. Like the component, the plugin renders ahead of playback and keeps up to ten minutes of audio.

## Known limitations

- Game mode has profiles for three games. Other games with NintendoWare's sound library rip in archive mode. Archive mode's model follows amiibo Festival's version of the sound library. A game with another version may play differently from the console. A JAudio game without a profile can't be ripped.
- The DSP's program reads the coefficients of its resampling filters from the DSP's ROM. No file holds that ROM. CSF uses the Wii's coefficients. They're very likely the same.
- A game's code can set up the effects of the console's sound library (reverb, chorus and delay). Archive mode plays them only for a game with an effect profile. Two games have one. Game mode plays without effects.
- The output is the TV's stereo mix. The GamePad's output, the Wii Remotes' speakers and surround aren't played.
- A sound that depends on values the game sets plays as it does before the game sets any. The variants of The Wind Waker HD's effects are the exception. A sequence that draws random numbers takes the same path every time.
- Sounds that play until the game stops them (such as ambiences) get two loops and a fade if the ripper can detect their loops. Otherwise, they play until their notes end. The limit is ten minutes.
- Only sequenced sounds are ripped. Use tools such as vgmstream for BFSTM streams. Wave sounds aren't ripped. Sequences whose data is in a group file that can't be found are skipped. The Wind Waker HD plays some of its music from streams. Its rip holds the music that it plays as sequences. It also holds the game's sound effects. JAudio plays those as sequences too. A few of the game's effects read the reverb of the room that they play in. The player doesn't set that value. Those effects make no sound in a rip. `csfrip` skips them.
- A JAudio game's rip runs the game's mixer on the emulated CPU. It renders far more slowly than other rips. A slow computer may not play it in real time.
- A seek back past the audio that the component or the XMPlay plugin keeps renders from the start of the track. Such seeks happen only in tracks longer than ten minutes and in endless playback.
- Encrypted games (disc images and installable titles) aren't read.
